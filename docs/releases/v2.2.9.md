# Wisp 2.2.9 / companion VSIX 1.14.6

This maintenance release repairs all 17 whole-codebase audit findings. It improves reliability and error handling without adding a provider or changing the signed Desktop protocol.

## Fixes

- **Account safety:** pending refreshes cannot undo sign-out or overwrite a newer account. Concurrent requests share renewal; malformed Claude/Grok replies preserve usable credentials. Identity is rechecked after persistence errors, and completed browser sign-in clears its timeout.
- **Saved settings:** cooperative locks preserve unrelated config edits. Async routing validation refuses stale routing state. Snapshot, preference and UI writes share the same boundary and report busy failures.
- **Streams and replay:** Chat/Messages disconnects abort local upstream work. Early SSE exit cancels the reader without waiting indefinitely. Advisor continuation retains signed, empty and redacted thinking in original text/tool order.
- **Discovery and commands:** optional model metadata has a bounded deadline and respects cancellation. Antigravity tests use authenticated dispatch; unsupported Argon tests refuse before transport. Grok key entry directs to OAuth.
- **Verification and docs:** layout checks isolate native discovery and exit nonzero on failure. Synthetic temporary paths are canonicalized while unsafe links remain refused. Current guides match manifests/code; historical formatting is restored. The dormant Gemini API adapter emits only complete usage totals.

## Verification and limits

The repaired source passed **1,975 core tests**, **201 TUI tests** (896 assertions), core/TUI typechecks, extension/webview compilation, Slot statusline checks and **34 hermetic screen captures**. A fresh independent review covered the 47-file repair diff and found one additional persistence-error identity race; regression tests reproduced it before correction. CodeRabbit then completed all 47 repair files with **0 issues**. Release metadata is verified separately.

The release workflow builds Windows x64, macOS arm64/x64 and Linux x64 binaries and runs isolated packaged launcher/Bridge and signed-Desktop smokes on each native runner before publication. Those synthetic package checks do not establish live provider or interactive host acceptance. No new provider-internal reasoning, cache benefit, native Desktop UI or installed VS Code host claim is made. Earlier ENOSPC, one intermittent Bridge-log test failure and React act warnings remain in the audit evidence.

Cancellation is cooperative: local abort does not guarantee remote computation stops. Renewal coalescing is per manager; cross-process OAuth grant serialization is not claimed. Separate Gemini API enrollment remains disabled. Desktop protocol **5**, instruction-hoisting consent and provider selection are unchanged.
