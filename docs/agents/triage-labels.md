# Triage labels

Use the canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`.

`ready-for-agent` means specified and suitable for autonomous work. `ready-for-human` marks a human-owned blocker. Blocked tickets remain blocked even when they carry `ready-for-agent`; check dependencies and the `Blocked by` section before selecting one.
