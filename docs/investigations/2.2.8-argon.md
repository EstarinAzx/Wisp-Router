## Current primary documentation

| Surface | Published behavior and implication |
| --- | --- |
| Product availability | Argon is listed for Ultra and Enterprise in the Antigravity app, CLI and IDE extensions, excluding Antigravity IDE. This is product availability, not evidence of this account's entitlement. [Google models](https://antigravity.google/docs/models) |
| Native CLI | Headless automation reuses cached credentials, supports NDJSON and conversation continuation, and documents Argon High/Medium slugs. Streamed stdin accepts user text; control messages and non-text blocks are rejected. Tool activity is emitted by the native harness. This establishes an automation surface, not a caller-owned raw model/tool-result API. [Headless protocol](https://antigravity.google/docs/cli/headless/) |
| Native custom tools | CLI MCP can supply local or remote tools. It may offer an integration direction, but tool registration alone does not establish preservation of Wisp's external call IDs, history and execution ownership. [MCP documentation](https://antigravity.google/docs/mcp/) |
| Python SDK | The reviewed quickstart uses `GEMINI_API_KEY`; Enterprise setup uses Google Cloud project/location credentials. It does not establish reuse of Wisp's personal subscription OAuth grant. [SDK setup](https://antigravity.google/docs/sdk/overview/) |
| Managed Agent API | The guide publishes API-key-authenticated `POST https://generativelanguage.googleapis.com/v1beta/interactions`, agent `antigravity-preview-09-2026`, and `agent_config.model: gemini-4-argon`. External functions resume with matching `call_id`, `previous_interaction_id` and environment. This is a distinct documented auth/transport contract; no API-key fallback was used. [Model selection and function continuation](https://ai.google.dev/gemini-api/docs/antigravity-agent) |

The documentation review does not establish a raw Argon subscription route for Wisp. It also does not prove that a native CLI/MCP integration is impossible. Generic CLI effort flags cannot establish how they interact with an Argon suffix; the paid API's model name cannot be transplanted into Cloud Code as an accepted ID.
